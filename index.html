Maginat è una distribuzione indipendente costruita da zero seguendo Linux From Scratch, con SysV init, un desktop Xfce pronto all'uso e un installer grafico per BIOS e UEFI. Maginat is an independent distribution built from scratch following Linux From Scratch, with SysV init, a ready-to-use Xfce desktop and a graphical installer for BIOS and UEFI.

Aggiornamenti firmati, anche per il kernel.Signed updates, kernel included.

Con la 0.1.2 un sistema installato può ricevere kernel e pacchetti nuovi senza reinstallare. Ogni elenco è firmato: se la firma non torna, Maginat non installa niente.With 0.1.2 an installed system can receive new kernels and packages without reinstalling. Every list is signed: if the signature does not match, Maginat installs nothing.

Esempio illustrativo. Limite: si aggiorna solo ciò che è pubblicato nel canale, non c'è gestione delle dipendenze e una nuova versione di Maginat resta una nuova ISO.Illustrative example. Limit: only what is published in the channel is updated, there is no dependency handling and a new Maginat version is still a new ISO.

Stato e limiti noti.Status and known limits.

Maginat è un progetto giovane. Questi sono i limiti della 0.1.2, su cui lavoriamo per la 0.1.3.Maginat is a young project. These are the known limits of 0.1.2, which we are working on for 0.1.3.

  • Gli aggiornamenti di sistema coprono solo ciò che viene pubblicato nel canale aggiornamenti (kernel e pacchetti, solo su sistema installato, senza gestione delle dipendenze): per una nuova versione si scarica la nuova ISO.System updates only cover what is published in the update channel (kernel and packages, installed systems only, no dependency handling): a new version means downloading the new ISO.
  • Alcune icone Flatpak possono apparire generiche; le icone della barra non usano ancora lo standard StatusNotifier.Some Flatpak icons may look generic; tray icons do not use StatusNotifier yet.
  • Niente driver stampante proprietari (per esempio HPLIP): funzionano le stampanti IPP e le scansioni senza driver.No proprietary printer drivers (e.g. HPLIP): IPP printers and driverless scanning work.
  • Solo X11, senza Wayland. Secure Boot non è supportato.X11 only, no Wayland. Secure Boot is not supported.

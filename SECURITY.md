# Security policy

## Supported versions
Only the latest release (currently 0.1.3) receives security fixes.

## Reporting a vulnerability
Please do NOT open a public issue. Use the **Report a vulnerability** button in the **Security** tab of this repository (private report).
I will reply as soon as possible.

## Política de seguridad / Politica di sicurezza
- ES: no abras un issue público; usa el botón **Report a vulnerability** en la pestaña **Security**.
- IT: non aprire una segnalazione pubblica; usa il pulsante **Report a vulnerability** nella scheda **Security**.
